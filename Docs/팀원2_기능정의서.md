# 팀원2 기능정의서 — 연출 + 투척물

> 갯벌 3페이즈, 양식장 확정. 등대는 제외되어 관련 코드 없음.
> 이 문서는 당신이 만들 범위만 다룹니다. 전체 그림이 궁금하면 `코드구조서.md`/`기술사양서.md` 참고.

## 이 문서의 범위

- 안개·화면 왜곡·비네트 연출
- 오염도 2단계 점프스케어 연출
- 엔딩 컷신 연출
- 조개껍데기 투척 오브젝트

---

## 이미 있는 것 (가져다 쓰면 됨)

| 이름 | 역할 |
|---|---|
| `EventBus.OnContaminationChanged(float)` | 오염도 값(0~100)이 바뀔 때마다 발행 |
| `EventBus.OnContaminationStageChanged(int)` | 단계(0/1/2/3) 넘을 때만 발행 |
| `EndingEvaluator.Evaluate(state)` | 엔딩 타입(Bad/Normal/True) 반환 |
| `InventorySystem.Instance.Has/Remove(itemId)` | 아이템 소모 판정 |
| `AudioManager.Instance.PlayOneShot(evt, pos)` | 효과음 재생 |
| (팀원1이 만들 예정) `DistractionZone.Trigger(Vector2 pos, float duration)` | 투척물이 호출할 대상 |

## 기능 1 — 안개·화면 연출 (Effects)

**상황:** 오염도가 오를수록 화면이 흐려지고 안개가 짙어짐.
**정상 동작:** `OnContaminationChanged`를 구독해, 값에 비례해 다음 3가지를 동시에 조절:
1. 안개 파티클(Particle System)의 Emission 강도
2. 화면 전체 왜곡 (Full Screen Pass Renderer Feature + Shader Graph, Fullscreen 타깃)
3. Volume의 Vignette·색보정

**예외:** 없음(연속값이라 항상 부드럽게 반응하면 됨).

## 기능 2 — 점프스케어 연출 (JumpscareDirector)

**상황:** 오염도 2단계 진입 시 화면 가장자리에 실루엣이 스치거나 갑자기 놀라는 연출.
**정상 동작:** `OnContaminationStageChanged(2)`를 구독해, 랜덤 간격으로 화면 가장자리 실루엣 스폰 또는 풀스크린 플래시+효과음 재생.
**예외:** 3단계로 넘어가면 빈도를 더 올릴지는 자유 재량(연출 취향껏).

## 기능 3 — 엔딩 연출

**상황:** 게임 종료 시 배드/노멀/진 엔딩 중 하나로 마무리.
**정상 동작:** `EndingEvaluator.Evaluate()` 결과에 따라 각각 다른 컷신 재생. 잼 스코프상 정적 이미지+텍스트로도 충분.
**주의:** 조각/조건은 원래 기획(4개 구역 전제)이 아니라 **갯벌+양식장 두 구역 클리어 여부 기준으로 재구성**해야 합니다. `EndingCondition`(SO)의 `requiredFlags`를 이 2개 기준으로 채워주세요.

## 기능 4 — 투척물 (조개껍데기)

**상황:** 플레이어가 마우스 클릭(또는 Q)으로 조개껍데기를 던짐.
**정상 동작:** 인벤토리에 조개껍데기가 있으면 소모하고, 마우스 위치로 투척 애니메이션/이펙트 후 **`DistractionZone.Trigger(targetPos, duration)` 호출**(실제 게임 로직은 이 안에서 처리되니, 내부 동작은 몰라도 됨 — 그냥 호출만 하면 됨).
**예외:** 조개껍데기가 없으면 "던질 것이 없다" 안내만 표시, 아무 일도 일어나지 않음.

**구현 힌트:**

```csharp
public interface IInteractable
{
    string Prompt { get; }
    void Interact();
}
```

`Throwable : MonoBehaviour, IInteractable`로 만들고, `Interact()` 안에서:
1. `InventorySystem.Instance.Has("shell")` 확인
2. 있으면 `Remove("shell")` + 마우스 좌표로 투척 이펙트/애니메이션
3. `AudioManager.Instance.PlayOneShot(투척효과음, targetPos)`
4. `targetZone.Trigger(targetPos, distractionDuration)` 호출 (7초 — 갯벌 1페이즈 기준, 페이즈마다 값 다를 수 있음)

---

## 다른 파트와의 접점

- **당신의 `Throwable`이 팀원1의 `DistractionZone.Trigger()`를 호출**해야 완성됩니다. `DistractionZone`이 먼저 나와야 완전히 테스트되니, 그 전까진 `Debug.Log`로 임시 확인하며 진행해도 됩니다.
- Effects·JumpscareDirector·엔딩 연출은 `ContaminationSystem`/`EndingEvaluator`만 구독하면 되니 **지금 바로 착수 가능**합니다.
