# 장곡리 (가제) — 기술 사양서 v0.1

> `코드구조서.md`(클래스 목록·관계)를 실제 구현 직전 수준까지 구체화.
> 시그니처·파라미터 의미·동작 규칙·이벤트 계약을 클래스 단위로 정리.
> 이 문서 승인 후 바로 `.cs` 파일 작성 착수.

## 1. Core

### `EventBus` (static)

| 이벤트 | 시그니처 | 발행 시점 | 구독자 |
|---|---|---|---|
| `OnContaminationChanged` | `Action<float>` (0~100) | 값 변경 시마다 | HUD, Audio |
| `OnContaminationStageChanged` | `Action<int>` (0/1/2/3) | 임계값 통과 시 | Vision, Effects, Movement, JumpscareDirector, Audio |
| `OnHauntPhaseAdvanced` | `Action<string huntId, int phaseIndex>` | 페이즈 Countered→다음 Threatened 전환 시 | HUD(진행 표시), Audio(ThreatState) |
| `OnHauntCleared` | `Action<string huntId>` | 마지막 페이즈 Cleared 시 | ObjectiveSystem |
| `OnThreatStateChanged` | `Action<string huntId, int state>` (0평온/1경계/2추격) | GhostAI 상태 전환 시 | AudioManager(`ThreatState` 파라미터) |
| `OnObjectiveFlagSet` | `Action<string flagId>` | ObjectiveSystem.SetFlag 호출 시 | HUD, EndingEvaluator |
| `OnPlayerDeath` | `Action` | 오염 100% 또는 즉사 판정 | SceneFlow(배드엔딩 진입), SaveModel |

**규칙:** 이벤트는 전부 `static`, 구독 해제는 각 구독자의 `OnDisable`에서 수행(누수 방지). 신규 이벤트 추가 시 이 표부터 갱신.

## 2. Systems

### `ContaminationSystem : MonoBehaviour`

| 멤버 | 시그니처 | 동작 |
|---|---|---|
| `Value` | `float` (읽기전용, 0~100) | 현재 오염도 |
| `Add` | `void Add(float amount)` | `Clamp(Value+amount, 0, 100)` 후 `OnContaminationChanged` 발행. 임계값(예: 30/60/90) 넘을 때만 `OnContaminationStageChanged` 추가 발행 |
| 임계값 | `const float Stage1=30, Stage2=60, Stage3=90` | 조정 가능한 상수. 씬 전환 간 유지 여부는 SaveModel 결정 대기 |

**주의:** `Add`는 음수도 허용(정화 아이템 등으로 감소 가능하게 열어둠). 단계는 **아래로 내려갈 때도** 이벤트 발행(히스테리시스 없음 — 필요하면 나중에 추가).

### `AudioManager : MonoBehaviour, IAudioService` (완성됨)

| 멤버 | 시그니처 | 동작 |
|---|---|---|
| `PlayOneShot` | `void PlayOneShot(EventReference evt, Vector3 pos, string localParam=null, float paramValue=0)` | 인스턴스 생성→(옵션)로컬 파라미터 설정→3D위치→재생→release |
| `PlayLoop` | `EventInstance PlayLoop(EventReference evt, Transform follow)` | `AttachInstanceToGameObject`로 위치 자동 추적, 호출자가 인스턴스 보관 |
| `StopLoop` | `void StopLoop(EventInstance inst, bool immediate=false)` | Fade-out 또는 즉시 정지 후 release |
| `SetGlobalParam` | `void SetGlobalParam(string name, float value)` | **Global 스코프 전용.** `Contamination`/`Region`/`ThreatState`/`RoomSize` |
| `SetInstanceParam` | `void SetInstanceParam(EventInstance inst, string name, float value)` | **Local 스코프 전용.** `Occlusion` — 인스턴스별 독립값 |
| `SetSnapshot` | `void SetSnapshot(EventReference snapshotEvt, bool on)` | 구역 리버브/ContaminationHaze/Death 전환 |

**FMOD 프로젝트 측 선행 조건:** `RoomSize`는 반드시 **Global** 파라미터로, `Occlusion`은 반드시 **Local** 파라미터로 생성. 스코프를 반대로 만들면 해당 호출이 조용히 무시됨.

### `DialogueSystem : MonoBehaviour`

| 멤버 | 시그니처 | 동작 |
|---|---|---|

| `ShowRapidPrompt` **(신규)** | `void ShowRapidPrompt(float timeout, Action onSurvive, Action onFail)` | 팝업 표시 후 `timeout` 내 플레이어가 **캔슬 입력**을 하면 `onSurvive`, 안 하면 `onFail`. 갯벌 3페이즈 "연속 3회 팝업, 빨리 무시" 구현용. 연속 호출 시 큐잉하지 않고 즉시 중첩 표시(문서상 "화면을 가림" 연출) |

|---|---|---|

### `DeadlineTimer : MonoBehaviour` (신규)

| 멤버 | 시그니처 | 동작 |
|---|---|---|
| `Start` | `void Start(float duration)` | 카운트다운 시작 |
| `OnTick` | `event Action<float remaining>` | 매 프레임(또는 0.1초 간격) |
| `OnExpired` | `event Action` | 시간 종료 시 1회 |
| `Cancel` | `void Cancel()` | 파훼 성공 등으로 조기 종료 |

**용례:** 갯벌 3페이즈는 `OnTick`에서 `ContaminationSystem.Add(2f * Time.deltaTime)` 호출(초당 2%). 양식장 3페이즈는 `OnExpired`에서 실패 처리(사망 또는 재시도).

## 3. Player

### `PlayerMovement` (완성됨)
`Rigidbody2D.MovePosition`, `Gravity Scale=0`, `Freeze Rotation Z`. `moveSpeed`는 `ContaminationSystem` 3단계 구독으로 배율 적용(곱연산, 원본 값 보존).

### `PlayerFacing` (신규)

| 멤버 | 시그니처 | 동작 |
|---|---|---|
| `Update` | (내부) | 마우스 월드좌표 X와 `transform.position.x` 비교 → `SpriteRenderer.flipX` 설정 |

**금지 사항:** `transform.localScale.x` 반전 사용 금지 — 자식 `VisionConeAim`까지 미러링되어 손전등 각도가 깨짐.

### `VisionConeAim` (완성됨)
Spot Light 2D를 마우스 각도로 회전(`-90°` 보정). `PlayerFacing`과 별도 컴포넌트로 완전 독립.

### `FootstepSurface` (완성됨, 트리거 방식 미확정)

| 멤버 | 시그니처 | 동작 |
|---|---|---|
| `surfaceMap` | `FootstepEventMap[]` (Inspector) | `LayerMask layer` 1개 ↔ `EventReference footstepEvent` 1개 |
| `floorMask` | `LayerMask` | 전체 재질 레이어 합집합(감지용) |
| `PlayFootstep` | `void PlayFootstep(Vector3 pos)` | `OverlapPoint(pos, floorMask)` → 레이어 매칭 → `AudioManager.PlayOneShot` |

**트리거 방식 (택1, §11 미확정):**
- A. 거리 기반: `FixedUpdate`에서 `rb.position` 델타 누적, `stepDistance` 도달 시 발화. 정지 시 리셋 대신 누적 정지.
- B. Animation Event(권장): 걷기 클립의 발 딛는 프레임에 `OnFootstepAnimEvent()` 직접 바인딩. 물리 틱 노이즈 원천 차단.

### `RoomSizeEstimator` (완성됨)
8방향 레이캐스트 평균거리 → `InverseLerp` → `AudioManager.SetGlobalParam("RoomSize", …)`. 0.2초 간격 샘플링.

### `ContaminationTarget`

| 멤버 | 시그니처 | 동작 |
|---|---|---|
| `OnTriggerEnter2D` | (내부) | 콜라이더 태그/레이어로 위협 판별 → `ContaminationSystem.Add(amount)`. `amount`는 위협 종류별로 Inspector 값 |

### `PlayerStamina` (조건부 — 등대 채택 시만)

| 멤버 | 시그니처 | 동작 |
|---|---|---|
| `Value` | `float` (0~100) | |
| `Drain` | `void Drain(float perSecond)` | 스프린트 중 매 프레임 |
| `Regen` | `void Regen(float perSecond)` | 비스프린트 시 매 프레임 |
| `CanSprint` | `bool` | `Value > 0` |

`PlayerMovement`는 `CanSprint`가 false면 스프린트 입력을 무시(걷기 속도로 강제 클램프).

## 4. Region

### `HauntController : MonoBehaviour`

```
enum HauntState { Dormant, Triggered, Threatened, Countered, ObjectiveReady, Cleared }
```

| 멤버 | 시그니처 | 동작 |
|---|---|---|
| `State` | `HauntState` (읽기전용) | |
| `CurrentPhaseIndex` | `int` (읽기전용) | |
| `Definition` | `HauntDefinition` (SO, Inspector 할당) | |
| `Trigger` | `void Trigger()` | `Dormant→Triggered`, `phaseIndex=0`, 즉시 `ActivateThreat()` 호출 |
| `ActivateThreat` | `void ActivateThreat()` | `State=Threatened`. 현재 페이즈의 `threats[]`에 `Activate()` 호출 |
| `MarkCountered` | `void MarkCountered()` | 현재 페이즈 `counters[]` 전부 `IsSatisfied`일 때만 호출 가능(가드). `State=Countered` → **다음 페이즈 있으면 `phaseIndex++`, `ActivateThreat()` 재호출** → 없으면 `State=ObjectiveReady`, `EventBus.OnHauntCleared` 발행 |
| `MarkObjectiveReady` | `void MarkObjectiveReady()` | 외부(목표물 Pickup)에서 호출, `Cleared`로 전환 |
| `Fail` | `void Fail(FailReason reason)` | 규칙 위반/데드라인 초과. `reason`에 따라 `ContaminationSystem.Add` 또는 `EventBus.OnPlayerDeath` |

**Update 루프:** 매 프레임 `State==Threatened`일 때만 현재 페이즈 `counters[]`를 폴링, 전부 만족 시 자동으로 `MarkCountered()` 내부 호출(외부에서 수동 호출 불필요 — Counter들이 이벤트 기반이면 폴링 대신 이벤트 구독으로 대체 가능, 최적화는 나중).

### `HauntDefinition` (SO)

```csharp
public class HauntDefinition : ScriptableObject
{
    public string huntId;
    public string regionLabel;      // AudioManager "Region" 파라미터 값
    public HauntPhase[] phases;
}
```

### `HauntPhase` (직렬화 클래스, SO 내부 배열 원소)

```csharp
[System.Serializable]
public class HauntPhase
{
    public MonoBehaviour[] threatBehaviours;   // IThreatBehavior 구현체 참조
    public MonoBehaviour[] counterConditions;  // ICounterCondition 구현체 참조
    public int requiredDistractionCount;       // 0이면 미사용
    public float safeWindowDuration;
    public bool useDeadline;
    public float deadlineDuration;
}
```

> Unity 인스펙터에서 인터페이스 배열을 직접 직렬화할 수 없어 `MonoBehaviour[]`로 받고, 런타임에 `as IThreatBehavior` 캐스팅. (관례적 우회법)

### 인터페이스 상세

**`IThreatBehavior`**
```csharp
public interface IThreatBehavior
{
    void Activate();
    void Tick();
    void Neutralize();
    bool IsNeutralized { get; }
    void SetProgress(float t); // 0~1, 미사용 시 no-op으로 구현
}
```

| 구현체 | 용도 | 특이사항 |
|---|---|---|
| `LureVoice` | 갯벌 아이들 | 진입 시 `DialogueSystem.ShowChoice`/`ShowRapidPrompt` 트리거, GhostAI 없음(정지형) |
| `Gaze` | 인면어 | 플레이어가 시야콘(손전등 포함) 안에 들어오면 즉시 `ContaminationSystem.Add(대량)` |
| `BehindStalker` | 등대 여인(연출용) | 플레이어 `facing` 벡터와 자기 위치 비교 — 뒤에 있는데 플레이어가 돌아보면 트리거 |
| `Chaser` | 등대 추적자 / 양식장 인면어(추격 모드) | `GhostAI` 보유, `SetProgress(t)`로 속도·템포 조절 |

**`ICounterCondition`**
```csharp
public interface ICounterCondition
{
    bool IsSatisfied { get; }
}
```

| 구현체 | 용도 |
|---|---|
| `RuleWatcher` | "대답 안 함" / "조명 그림자 시 정지" 같은 위반-감지형. 위반 즉시 `HauntController.Fail()` 직접 호출(만족 여부와 별개 채널) |
| `DistractionZone` | §4-2 참고 |
| `Concealment` | §4-2 참고 |
| `ToolCombine` | 인벤토리에 특정 조합 결과 아이템 보유 여부 확인(기름통+조명탄) |

**`IInteractable`**
```csharp
public interface IInteractable
{
    string Prompt { get; }
    void Interact();
}
```
`Throwable`(조준→투척, `DistractionZone.Trigger(targetPos)` 호출), `Generator`(조건부 `IMinigame` 래핑), `Pickup`(단순 획득 → `IObjective.SetFlag`), `CombineStation`.

**`IMinigame`** (조건부 — 양식장 채택 시만)
```csharp
public interface IMinigame
{
    void StartOrResume();
    void Interrupt();   // 진행 상태 보존한 채 일시정지
    bool IsComplete { get; }
    int SuccessCount { get; }
}
```
`Generator`가 내부에 보관, `GhostAI`의 시선 이벤트 구독하여 `Interrupt()` 자동 호출 → 플레이어가 `Concealment` 진입 후 재개하면 `StartOrResume()`으로 이어서 진행(0으로 안 돌아감).

### 신규 공용 컴포넌트

**`DistractionZone`**
```csharp
public class DistractionZone : MonoBehaviour, ICounterCondition
{
    public void Trigger(Vector2 targetPos, float duration);
    public bool IsActive { get; }          // 현재 분산 중인지
    public bool IsSatisfied { get; }       // requiredCount만큼 Trigger 호출됐는지
}
```
`IThreatBehavior.Tick()` 구현체들이 `IsActive`를 읽어 이동 목표를 분산 지점으로 임시 변경.

**`Concealment`**
```csharp
public class Concealment : MonoBehaviour
{
    public bool PlayerInside { get; }  // Trigger enter/exit로 갱신
}
```
`GhostAI.Perception`이 시각/청각 판정 직전에 플레이어의 `Concealment.PlayerInside`를 확인, true면 해당 채널 스킵.

## 5. AI

### `GhostAI : MonoBehaviour`

```
enum BehaviorState { Patrol, Suspect, Chase, Retreat, Berserk }
```

| 멤버 | 시그니처 | 동작 |
|---|---|---|
| `State` | `BehaviorState` (읽기전용) | 자율 전이는 `Perception` 결과 기반 |
| `ForceState` **(신규)** | `void ForceState(BehaviorState state, float duration)` | 자율 전이 일시 정지, `duration` 후 자동으로 `Patrol` 복귀(또는 Despawn). 양식장 3페이즈 광폭화용 |
| `SetProgressScale` **(신규)** | `void SetProgressScale(float t)` | 0~1. 이동속도·인지범위·발소리 템포에 곱연산 커브 적용. 등대 층수 escalation용 |

### `Perception`
시각(각도+거리+`Physics2D.Raycast` 차폐) / 청각(`OnNoiseEmitted` 반경) / 접촉(트리거) 3채널. `Concealment.PlayerInside`가 true인 프레임엔 시각·청각 판정 스킵(접촉은 예외 — 물리적으로 닿으면 항상 유효).

### `LitVisibility`

| 멤버 | 시그니처 | 동작 |
|---|---|---|
| `Update` | (내부) | 플레이어 시야콘 각도+거리+차폐(기존 시야 로직 재사용) 판정 → `SpriteRenderer.enabled` 토글 |

**주의:** 렌더링만 게이트하며 `GhostAI`의 인지·이동 로직은 이 컴포넌트와 무관하게 계속 동작(안 보여도 AI는 계속 추적 가능 — 의도된 공포 연출).

## 8. 구현 순서 권장

1. Core 전부 (EventBus 먼저 — 다른 모든 것이 여길 참조)
