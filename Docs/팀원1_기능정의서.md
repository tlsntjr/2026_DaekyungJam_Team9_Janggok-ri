## 구현할 인터페이스 (계약)

```csharp
public interface IThreatBehavior
{
    void Activate();             // 페이즈 시작 시 호출됨

    void Neutralize();           // 페이즈 종료 시 정리
```

## 기능 1 — 갯벌 2페이즈

**상황:** 안개가 짙어져 시야 반경 30% 감소. 귀신 실루엣이 2마리로 늘어남.
**정상 동작:** 조개껍데기를 서로 다른 방향으로 3번 나눠 던져 두 귀신을 모두 분산시켜야 다음 발판으로 이동 가능.
**예외:** 한쪽만 분산시키고 이동하면 나머지 한 귀신에게 발각(→ `HauntController.Fail`).

**구현 힌트:**
- `DistractionZone`을 귀신 2마리 각각에 붙여 2개 인스턴스로 관리 (또는 `requiredCount=3`을 두 존이 합산하도록 설계해도 됨 — 편한 쪽으로)
- `LureVoice`를 복제하거나, 내부에서 귀신 2개를 함께 관리하도록 확장
- 시야 30% 감소는 오염도 시스템과 무관한 **이 페이즈 한정 임시 효과** — 진입 시 Light2D 파라미터를 낮췄다가, 페이즈 종료 시 원복

## 기능 2 — 갯벌 3페이즈

**상황:** 밀물이 들어와 가만히 있어도 오염도가 초당 2%씩 상승. 질문창이 3회 연속으로 화면을 가리며 뜸.
**정상 동작:** 질문창을 빠르게 넘기고(캔슬), 동시에 조개껍데기를 5번 타이밍 맞춰 던져 사방의 귀신을 떼어내야 함.
**예외:** 질문창을 제때 안 넘기면 즉시 실패. 데드라인 전 탈출 못하면 실패.

**구현 힌트:**
- `DeadlineTimer.Begin(duration)`으로 시작 → `OnTick`에서 `ContaminationSystem.Add(2f * Time.deltaTime)`
- 연속 질문창 3회는 `DialogueSystem.ShowRapidPrompt(timeout, onSurvive, onFail)`를 순차로 3번 트리거
- `DistractionZone.requiredCount = 5`로 두면 파훼 조건은 `HauntController`가 자동 폴링해서 처리

## 기능 3 — 양식장 발전기 미니게임

**상황:** 인면어는 시야(손전등 포함)에 들어오면 즉시 덮침(치명적), 소리에 극도로 민감함.
**정상 동작:** 발전기를 타이밍 미니게임으로 가동(1번째=2회 성공, 2번째=4회 성공)하면 인면어가 소음 쪽으로 쏠려 그 틈에 이동 가능.
**예외 (2번째 발전기 한정):** 가동 도중 인면어가 이쪽을 보면 미니게임이 중단되고, 상자 뒤에 5초 숨어야 재개(총 2회 반복). 시간 안에 해결 못 하면 인면어 재접근.

**구현 힌트:** 새 인터페이스가 필요합니다.

```csharp
public interface IMinigame
{
    void StartOrResume();
    void Interrupt();       // 진행 상태 보존한 채 멈춤 — 0으로 리셋되면 안 됨
    bool IsComplete { get; }
    int SuccessCount { get; }
}
```

`Generator : IInteractable`가 내부에 `IMinigame` 구현체를 들고 있는 구조로 만드세요. 미니게임 자체 입력 판정(타이밍 맞춰 스페이스바 등)은 자유롭게 설계해도 되고, **그 미니게임의 화면 표시(UI)도 당신 담당**입니다(맵별 기믹으로 분류했으니 팀원2 몫 아님).

## 기능 4 — 양식장 인면어 AI

**상황:** 평소엔 시야 판정만 하다가, 3단계(녹음기 획득 후)엔 실제로 쫓아오고, 녹음 재생 시 미쳐 날뜀.
**정상 동작:** 시야 밖/소리 없음 → 대기. 시야 노출 → 오염 급상승. 3단계 진입 → 추격. 녹음 재생 → 예측불가 이동(광폭화), 60초 안에 탈출.
**예외:** 60초 데드라인 초과 시 실패 처리.

**구현 힌트:**

```csharp
public enum BehaviorState { Patrol, Suspect, Chase, Retreat, Berserk }
```

- `Gaze : IThreatBehavior` — 시야각+거리+차폐 판정, 노출 시 `ContaminationSystem.Add`
- `GhostAI` — 실제 이동. `ForceState(BehaviorState.Berserk, duration)`로 3단계 광폭화를 **강제로** 진입시킴(자율 인지 아님, 스크립트가 직접 호출)
- `SetProgressScale(t)`는 이번 맵엔 사용 안 함(등대 전용 기능이었음) — 인터페이스엔 남아있으니 빈 구현으로 두면 됨

## 다른 파트와의 접점

- **팀원2가 만드는 `Throwable`이 당신의 `DistractionZone.Trigger(pos, duration)`을 호출합니다.** `DistractionZone`을 먼저 완성하고, 이 메서드 시그니처를 팀원2에게 공유해주세요.
- 인면어의 "손전등 밖에선 안 보임" 연출은 이미 완성된 `LitVisibility`를 그대로 붙이면 됩니다.
